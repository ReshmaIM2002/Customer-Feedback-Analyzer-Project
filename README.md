# Customer Feedback Analysis using Python

Description
This project analyzes customer feedback using Python. It stores customer names, feedback, and ratings.

 Features
- Add new customer feedback.
- Clean text by removing punctuation and extra spaces.
- Convert feedback into lowercase.
- Count specific words such as Good, Poor, and Excellent.
- Calculate average customer ratings.
- Find the longest feedback.
- Identify unique words.
- Sort feedback based on ratings.
  
 Technologies Used
- Python
- Lists and Dictionaries
- Loops and Functions
- String Operations
- Lambda Functions

 Conclusion
This project helps to understand basic Python programming and customer feedback analysis.
